## Passport Management System

### Introduction
The Passport Management System is designed to manage passport applications and verify applicant details using a central computer.

The applicant submits the passport application to the Passport Office. The office forwards the applicant's details to the Central Computer for verification. The Central Computer checks the details and sends approval or rejection to the Passport Office. If the application is approved, the Passport Issuing Officer issues the passport to the applicant.

### Actors
1. Applicant
2. Passport Office Administrator
3. Central Computer
4. Verification Officer
5. Passport Issuing Officer

### Main Functions
- Submit Passport Application
- Provide Applicant Details
- Forward Details to Central Computer
- Verify Applicant Details
- Retrieve Applicant Records
- Approve or Reject Application
- Receive Verification Result
- Issue Passport
